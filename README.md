# Blue Energy PH Landing Page

Welcome to the **Blue Energy PH Landing Page** repository. This project represents the official online presence for Blue Energy PH, a company specializing in truck parts and related automotive solutions.

## 🌐 Live Site

[https://blue-energyph.netlify.app/](https://blue-energyph.netlify.app/)

## 📖 Project Overview

The landing page is designed to showcase Blue Energy PH's products, services, and contact information. It provides a user-friendly interface for customers to explore available truck parts and learn more about the company.

### Key Features

* Responsive design for desktop, tablet, and mobile devices.
* Display of truck parts and product categories.
* Clear navigation and call-to-action buttons.
* Integrated contact section for inquiries and quotations.

## 🛠 Technologies Used

* **HTML5**: Structure of the landing page.
* **CSS3**: Styling and layout.
* **JavaScript**: Interactivity and animations.
* **Netlify**: Hosting the live site.
